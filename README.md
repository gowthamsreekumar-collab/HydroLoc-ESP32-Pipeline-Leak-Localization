# HydroLoc-ESP32-Pipeline-Leak-Localization
Autonomous edge-embedded framework for real-time water pipeline rupture detection and exact localization using ESP32. Implements physical acoustic wave modeling, active analog front-end conditioning, 12-bit ADC digitization, and sub-sample GCC-PHAT TDOA profiling with 0.01 m median error, SSD1306 OLED telemetry, and audible alarm actuation.
